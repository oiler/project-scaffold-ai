# Operations

Document the parts required to run and support the product:

- environments and configuration;
- deployment and rollback;
- migrations, backup, and recovery;
- observability and alert ownership;
- expected failure modes and runbooks;
- capacity and cost constraints;
- incident and support procedures;
- release and deprecation processes.

Use exact, tested commands when procedures become operational. Keep secrets and environment-specific credentials out of the repository.
