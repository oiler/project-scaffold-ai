# Product Documentation Policies

- [`CHANGE-CONTROL.md`](CHANGE-CONTROL.md) defines which records may change and how corrections are made.
- [`VERSIONING.md`](VERSIONING.md) defines minor-version folders and patch releases.
- [`TRACEABILITY.md`](TRACEABILITY.md) connects evidence, requirements, implementation, verification, and releases.

These policies are repository defaults. A version may add stricter requirements but must document any waiver from them.
